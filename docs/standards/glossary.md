# Glossary

## Purpose

This page defines the shared vocabulary used across the handbook.

## Terms

### Source of truth

The authoritative place where a rule or state must be maintained.

### Stable `main`

A protected branch that must remain mergeable, releasable, and validated by CI.

### Task

A focused technical work item that can usually be delivered by one pull request.

### Feature

A functional capability visible to users or product stakeholders.

### Spike

A time-boxed investigation used to reduce uncertainty.

### Promotion

The controlled act of moving a validated environment state from `preprod` to `prod`.

### Orchestration

The management of deployed versions and environment state, separate from business logic.
